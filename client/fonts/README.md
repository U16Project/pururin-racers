# client/fonts/

日本語 UI 用の同梱フォント置き場。

## NotoSansJP-Regular.otf

**Noto Sans JP**（日本語だけの版。SIL Open Font License）

- 用途: Godot クライアントの UI テキスト（ラベルなど）で、ひらがな・漢字をきれいに表示するため
- 日本語・中国語・韓国語をまとめた版（Noto Sans CJK、約19MB）から、日本語だけの版（約4.5MB）に替えた（ウェブ版の読み込みを軽くするため）
- Godot 4.7 が読む `.import` は同梱してよい（設定の共有用）。手元で開き直すと再生成・更新されることがある
- 入手元: <https://github.com/notofonts/noto-cjk> の `Sans/SubsetOTF/JP/NotoSansJP-Regular.otf`
