# client/fonts/

日本語 UI 用の同梱フォント置き場。

## NotoSansCJK-Regular.ttc

**Noto Sans CJK**（日本語向け。SIL Open Font License）

- 用途: Godot クライアントの UI テキスト（ラベルなど）で、ひらがな・漢字をきれいに表示するため
- Godot 4.7 が読む `.import` は同梱してよい（設定の共有用）。手元で開き直すと再生成・更新されることがある
- 再取得例（Ubuntu）: `sudo apt install fonts-noto-cjk` のあと  
  `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc` をこのディレクトリへコピー
- 旧プロジェクト（shelved full-era）から同梱したものも同じ系統
