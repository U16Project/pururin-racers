# Pururin Racing Game - 架空生物レーシングゲーム

かわいい架空生物が、自分自身の身体で走るレーシングゲームです。

## 📖 プロジェクト概要

Pururin を操作してレースを楽しむ、大人向けのレーシングゲームプロジェクト。

- **GitHub リポジトリ**: https://github.com/U16Project/pururin-racers
- **開発者**: U16Project
- **方向性**: チョコボレーシングのような親しみやすい架空生物レース × ギャロップレーサーのような駆け引き

## 🎮 ゲームコンセプト

### 基本コンセプト
- **かわいい架空生物**が、自分自身の身体で走るレーシングゲーム
- **「どの生物を育てるか」「どの能力に特化するか」**を楽しむ育成要素
- **自転車競技のような集団走行**、空気抵抗（ドラフティング）の戦略性

### レースシステム
#### 基本的なレース要素
- 最高速度 / 加速 / スタミナ / 瞬発力
- 位置取り / 集団走行 / コース適性
- 風の影響など

#### レース中の戦略
| 戦術 | 特徴 |
|------|------|
| **逃げ** | 最初から先頭を維持。速度は高いがスタミナ消費が大きい |
| **先行** | 集団前方で機会をうかがう |
| **差し** | 集団内で力を温存し、終盤で抜く |
| **追込** | 最後まで耐えて、最後のスパートで勝負 |

---

## 💨 空気抵抗（ドラフティング）システム

自転車競技のように、前方の生物の後ろにつくことで空気抵抗を減らす。

### 空気抵抗率（例）
- **先頭**: 100%（基本）
- **2 番手**: 80%
- **集団中央**: 60～70%
- **最後尾**: 50～60%

### 効果
- ✅ スタミナ消費減少
- ✅ 速度維持
- ✅ 終盤のスパート用に温存

**先頭メリット例:**
- わずかな速度上昇
- 観客による気力上昇
- 逃げ成功ボーナス

---

## 🌬️ 風システム

コースごとに風条件を設定。

| 風タイプ | 特徴 | 有利な戦略 |
|----------|------|-----------|
| **向かい風** | 単独走行が不利、集団走行が有利 | ドラフティング重視 |
| **追い風** | 逃げが成功しやすい | リーダーシップ重視 |
| **横風** | 集団が崩れる、位置取りが重要 | コーナリング性能 |

風属性や生物特性によって影響を変化させる。

## 🏆 ステータス育成システム

限られたポイントを自由配分するステータスシステム。

### ステータス一覧
| ステータス | 説明 |
|------------|------|
| **最高速** | 最大速度 |
| **加速** | スタート、立ち上がり |
| **スタミナ** | 長距離性能、疲労耐性 |
| **瞬発力** | ラストスパート |
| **集団適性** | ドラグティング効果 |
| **体格** | 風よけ能力、接触耐性 |
| **操作性** | コーナリング性能 |

### ステータスバランス設計
完全自由配分では最適解が生まれる可能性があるため、
能力値が高くなるほど必要ポイントを増やす。

```
1～50:     1ポイント
50～80:    2ポイント
80～100:   4ポイント
```

#### 育成例

**短距離特化型**
- 最高速 / 加速 / 瞬発力
- 短いレースで強い

**万能型**
- 全能力をバランス配分
- 複数条件の大会で安定

**長距離型**
- スタミナ / 集団適性
- 持久戦向き

## 🎯 レース体系

「最強キャラ」ではなく、「大会条件に合わせたキャラ作り」を楽しむ。

### リーグ制度
```
短距離 ↓
中距離 ↓
長距離
```

または、複数レースのポイント制を採用。

## 🔥 属性システム

基本属性：地・水・火・風

| 属性 | タイプ | 特徴 | 得意 |
|------|--------|------|------|
| **地** | 耐久・安定型 | スタミナが高い、悪路に強い、接触に強い | 山岳 / 長距離 |
| **水** | 柔軟・集団型 | コーナリング性能、集団走行能力、ドラフティング適性 | 雨 / テクニカルコース |
| **火** | 瞬発型 | 加速が高い、終盤の爆発力 | 短距離 / 直線勝負 |
| **風** | 高速・空力型 | 最高速度、風への耐性 | 高速コース / 強風 |

※ 属性による固定的な強弱ではなく、コース条件による有利不利を重視。

## 🦄 キャラクターデザイン

### イメージ
- スライム系 / 変形生物系 / まるいフォルム
- シルエット / 動き / 特徴的なアクセント

### 属性ごとのデザイン案
| 属性 | デザイン要素 |
|------|-------------|
| **水** | 透明感、泡、水流 |
| **地** | 岩、鉱石、苔 |
| **火** | 炎、光る核 |
| **風** | 羽、流線型 |

### モーション設計
リアルな動物より、架空生物らしい動きを重視。

- スライム系：伸びる / 縮む / 跳ねる
- パワー型：大きく踏み込む / 地面を揺らす
- 高速型：体を流線型に変形する
