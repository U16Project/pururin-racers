# Pururin Racing Game - 架空生物レーシングゲーム

かわいい架空生物が、自分自身の身体で走るレーシングゲームです。

## 📖 プロジェクト概要

Pururin を操作してレースを楽しむ、戦略性を重視した育成型レースゲームプロジェクト。

- **GitHub リポジトリ**: [https://github.com/U16Project/pururin-racers](https://github.com/U16Project/pururin-racers)
- **開発者**: U16Project
- **方向性**: 育成要素が魅力の架空生物レース × 高度な戦術性が特徴のレース

## 🎮 ゲームコンセプト

### 基本コンセプト

- **かわいい架空生物**が、自分自身の身体で走るレーシングゲーム
- **「どの生物を育てるか」「どの能力に特化するか」**を楽しむ育成要素
- **自転車競技のような集団走行**、空気抵抗（ドラフティング）の戦略性

### レースシステム

#### 基本的なレース要素

- 最高速度 / 加速 / スタミナ / 瞬発力
- 位置取り / 集団走行 / コース適性
- 風の影響など

#### レース中の戦略


| 戦術     | 特徴                         |
| ------ | -------------------------- |
| **逃げ** | 最初から先頭を維持。速度は高いがスタミナ消費が大きい |
| **先行** | 集団前方で機会をうかがう               |
| **差し** | 集団内で力を温存し、終盤で抜く            |
| **追込** | 最後まで耐えて、最後のスパートで勝負         |


---



## 🎯 ゲームの方向性

かわいい架空生物が、以下の要素を駆使して競う。

- ✅ **育成** / **属性** / **位置取り** / **空力** / **スタミナ管理**

勝つためには、

- 「一番速い生物を作る」だけでなく、
- 「どの条件のレースに合わせるか」「いつ仕掛けるか」「集団で力を温存するか」を考える。
