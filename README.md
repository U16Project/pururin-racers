# ぷるりんレーサーズ

かわいい架空生物「ぷるりん」が、自分自身の身体で走るレーシングゲームです。
あなたはトレーナーとして、走る位置と走る力を指示します。

**開発中**です。Windows・Linux（SteamOS を含む）向けに、Steam などのプラットフォームでの配信を予定しています。

## 現在遊べる内容

| モード | 内容 |
|---|---|
| オフラインフリー対戦 | 自分と CPU（1〜7体）で走ります。距離は 1200・1600・2000・2400・3000m から選べます |
| ともだち対戦 | 部屋を作って友だちと走ります。パスワードを設定でき、CPU を加えることもできます。途中で抜けた人の分は CPU が引き継ぎます |
| オンラインフリー対戦 | ルームにエントリーし、呼び出しに応じて参加します。人数が集まるか待ち時間が過ぎると始まり、足りない枠は CPU が入ります |
| ぷるりん作成コーナー | 名前・属性・脚質を決め、8つの能力に点を配分し、色や部品で見た目を作ります |

## 遊び方

基本の操作は **左右でライン、上下で出力（ノッチ）** です。

- 出力は 1〜6 の段階です。上げると力強く走り、下げると力を抑えます。
- 左右・ブレーキは押している間だけ働きます。ダッシュ・ブースト・視点切り替えは 1 回押します。
- 心拍とスタミナの管理と、レース展開への柔軟な対応力が問われます。

キーボード、ゲームパッド、画面のボタンで遊べます。詳しい操作は [レース操作ガイド](docs/レース操作マニュアル.md) を見てください。

## 走りの仕組み

勝つためには、能力の配分と、レース中の力の使い方の両方が大切です。走りの仕組みの主なところを紹介します。詳しい計算の説明は [計算リファレンス](docs/現行ローカルレース計算リファレンス.md) にあります。

### 8つの能力と属性

最高速・加速力・スタミナ・心肺・空力・集団・接触耐性・操作性の8つです。配分する点は、それぞれ 1〜10、合計 40 です。属性のボーナスを受ける能力は、最大 12 まで上がります。

属性は地・水・火・風の4つで、属性ごとに得意な能力 2 つに +2 が加わります。地はスタミナ・接触耐性、水は操作性・集団、火は加速力・心肺、風は最高速・空力です。

### 脚質

脚質は、得意な位置と、能力が上がる区間を決める特性です。

| 脚質 | 得意な位置 | 能力が上がる区間 |
|---|---|---|
| 逃げ | 前方 | 最初の4分の1で加速力 |
| 先行 | 前寄り | 2番目の4分の1で空力 |
| 差し | 後ろ寄り | 3番目の4分の1で集団 |
| 追込 | 後方 | 最後の4分の1で最高速 |

得意な位置で走っていると全能力が少し上がり、離れすぎると少し下がります。

### 心拍とスタミナ

- 出力を上げるほど心拍が上がり、体力（燃料）も減ります。
- 心拍が 200 を超える走りが続くと、走る力が落ちていきます。
- 体力が尽きると、さらに走る力が落ちます。
- ダッシュは短い間だけ加速する技、ブーストは 1 レースに 3 回だけ使える強い加速です。どちらも、心拍と体力を余計に使います。

### 風よけ（ドラフト）

前の走者に近い位置につくと、空気抵抗が減って、速度を伸ばしやすくなります。効果は距離や横のずれ、前方の走者数によって変わり、集団の能力が高いほど効きやすくなります。また、後ろに走者がいると、前を走る側の空気抵抗も少し減ります。空力が高いほど、この効果も大きくなります。
