# build/

Godot からの **エクスポート成果物**（実行ファイル・ブラウザ版など）の置き場。

ソースは `client/`。ここには配布用バイナリだけを出す。

## 推奨パス（Export 先）

`client/` から見て:

| プラットフォーム | 例 |
|------------------|-----|
| Linux | `../build/linux/` |
| Windows | `../build/windows/` |
| Web（テスト用） | `../build/web/` |

Android は配信先ではない。ブラウザ版と同じく試し用の候補で、書き出し設定・動作はまだ確かめていない。現在、Android 用の書き出し設定は無い。

## Git

このディレクトリ配下の成果物は **コミットしない**（`.gitignore` で除外）。  
README と ignore だけリポジトリに含める。
