# World Builder - ぷるりんレーサーズの世界観構築

ぷるりんレーサーズの世界観、ルール、アイデアを雑談しながら構築していくスキル。

## 概要

ユーザーと対話しながら、以下の要素を話し合いながら設計案に追記していきます：

- 🌍 **世界観・背景設定**（舞台、歴史、文化など）
- 🏆 **大会・イベント**（レースのルール、賞金、特別戦など）
- 🎭 **生物・キャラクター**（新しい種族、個体、関係性など）
- 📜 **ルール・メカニクス**（追加システム、特殊能力、バランス調整など）

## 機能

### 💬 雑談モード
ユーザーのアイデアを聞き取り、自然な会話の流れで深掘りしていきます。

### 📝 設計案への追記
話し合った内容を整理し、`ぷるりんレーサーズ_設計案.md` に適切に追記します：

- **新規セクション追加**（新しいトピックの場合）
- **既存セクションの拡張**（関連する内容がある場合）
- **フォーマット統一**（表形式、箇条書きなど）

### 🎯 提案機能
ユーザーが迷っている場合に、いくつかの選択肢を提案します：

```
アイデア A: 〜の特徴を持つ
アイデア B: 〜の特徴を持つ
アイデア C: 〜の特徴を持つ

どの方向性が気になりますか？
```

## パス

- @workspace:ぷるりんレーサーズ_設計案.md - 設計書の全体構造と既存内容を確認
- @workspace:* - プロジェクト全体の文脈を理解

## ビジュアル資料を作るときの必須規則

キャラクター、キービジュアル、背景、レース場の画像を生成・修正するときは、保存前に必ず以下を確認する。

### ぷるりんの正本

- 必ず [`docs/reference/ぷるりん素体デザインシート_v0.7.png`](../../docs/reference/ぷるりん素体デザインシート_v0.7.png) を形状リファレンスにする。
- ぷるりんの形は文章で新規設計しない。生成時はこの画像を一次資料として渡し、出力を画像同士で見比べる。
- ぷるりんは直径約1.5m。人が抱える、手に持つ、肩に乗せるサイズではない。
- 人間との比較では、人間の身長を約1.8mとし、ぷるりんの高さ・幅はおおむね人間の8割前後にする。画面手前へ誇張して巨大化しない。
- 丸〜やや横長で地面に接する、単純なスライム型。足、腕、手、耳、翼、角、複雑な解剖は付けない。
- 基本形は、柔らかい上部の小さな突起、横の小さな張り出し、単純な目と口を持つ。
- 属性差は色、透明感、内部模様、ハイライト、小さな属性表現で示す。別種のモンスターや複雑な装飾に変えない。
- 属性差分は全員を同じ色替えにしない。素体シートを基準に、地は暗い茶〜灰茶と小石、 水は青と水滴・水面表現、火は赤橙と小さな炎・尖った火の張り出し、風は淡い緑〜青緑と葉・風の流れで区別する。
- 目や属性パーツも全員同一にしない。地・火はやや強い目つき、水は穏やかな丸い目、風は軽く柔らかい目など、素体シートの差分を保持する。
- トレーナーはぷるりんに騎乗せず、ぷるりんを手で持たない。

### レース場の正本

- レース場は城や大建築物で周囲をぐるっと囲まない。
- 最初のレース場案を基準に、開けた土地に独立した大きな楕円コースを置く。
- 一周2000m以上。画面内でコースの長い直線と大きな曲線が読み取れる広域構図にする。
- 観客席・王族席は片側または一部に置き、城は遠景または画面端に置く。
- 直径1.5mのぷるりんが人間より大きく見えるよう、スタート地点や観客との比較対象を入れる。

### 異世界移動の正本

- 主人公は睡眠によって現実世界と異世界を行き来する。
- 物理的なポータル、門、渦、魔法陣、光の入口、次元の裂け目は設定にない。
- キービジュアルでは、主人公がすでに異世界の風景に立っている構図、または目覚め・夢を想起させる控えめな表現にする。

### 紋章・旗の正本

- 採用紋章は [`docs/reference/world/purulin_emblem_v01.png`](../../docs/reference/world/purulin_emblem_v01.png) を参照する。
- 正しい構成は、上が青い水滴、左が緑の風の渦、右が橙色の火、下が黄土色の岩、中央が淡い円形の核、濃紺の輪郭。
- 四分割の円盤、花、百合、フルール・ド・リス、王冠、十字、盾型の既存紋章に置き換えない。
- 紋章は公式の旗・王族席・公共施設に限定し、商店の看板や全ての装飾へ反復しない。店舗はパン、花、野菜、陶器、布など商品を示す絵にする。

### 生成後の拒否条件

スキルを更新しただけでは、過去に生成した画像は合格にならない。新規生成・修正版・既存画像の採用候補は、保存先を確定する前に必ず実ファイルを開いて目視確認する。画像生成ツールのプレビューを見ただけで合格扱いにしない。次のどれかに該当したら採用せず、プロンプトを修正して再生成する。

- 女性トレーナーやキービジュアルが、線・光沢・装飾過多の複雑なAIイラストになっている
- ぷるりんが手持ちサイズ、球体だけ、動物、ロボット、手足付きの別生物になっている
- ぷるりんの素体シートの形状から大きく外れている
- レース場が狭い、円形広場に見える、建物に囲まれている、2000m級の広さが読めない
- スタートラインがコースに対して直角でない、ぷるりんが観客側を向いている、または走行方向と第一コーナーが読めない
- ぷるりんの横幅・高さ・突起・横の張り出しが素体デザインシートと異なる
- 4属性が単なる同一形状の色違い、または地属性が黄色・クリーム色になっている
- 旗の紋章が採用紋章と違う、四分割マークやフルール・ド・リスが出ている
- 異世界への物理的な入口、ポータル、魔法陣、次元の裂け目が描かれている

確認結果は、少なくとも「絵柄」「ぷるりんの形と大きさ」「レース場の平面形状」「旗・紋章」「世界設定との矛盾」の5項目で記録する。1項目でも未確認なら、`v01` や `v02` を正式採用版として報告しない。

採用版を保存するときは旧版を削除せず、`v02` などの版番号で保存し、資料一覧の参照先だけを更新する。
