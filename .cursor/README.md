# `.cursor` について

このディレクトリは **開発中、GitHub リポジトリに含めて共有する** 方針です（意図的にバージョン管理対象）。

| 配下 | 内容 |
|------|------|
| `rules/` | エージェント向けプロジェクトルール |
| `agents/` | MAGI／実装パイプライン用の役割定義 |
| `skills/` | MAGI 審議・実装パイプラインなどの Skill |

## 公開時

リポジトリを広く公開する段階では、**`.cursor/` ごと削除またはリポジトリ外へ移す想定**です（開発用の運用・エージェント設定のため）。

開発中のクローズ運用では、チーム／自分用に GitHub 上に置いたまま使う。
