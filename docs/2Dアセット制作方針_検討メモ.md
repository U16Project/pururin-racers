# プルリンレーサーズ：2Dアセット制作方針メモ

**状態:** 参考・議論中（仕様としては未確定）
**作成日:** 2026/09/13

この資料は、プルリンレーサーズで使う 2D 素材の制作方針を保存するための案である。完成仕様ではなく、用途別の制作方法と共通アート規格を検討するために参照する。

## 1. 基本方針

2D 素材はすべてを同じ方法で作らず、用途ごとに制作方法を分ける。

- 一枚絵・キービジュアル
- UI アイコン
- ロゴ・タイトル文字
- 表情パーツ
- 模様・ほっぺ
- エフェクト画像
- コース上の 2D 看板
- 宣伝用素材

共通するアート方向は、**丸い／ぷるぷる／柔らかい／明るい／ポップ／かわいい／単純／視認性が高い／リアルすぎない** とする。

プルリンそのものは一般的な小型モンスターではなく、**非常に単純なスライム型生物**を基本とする。

## 2. プルリンの 2D 表現

基本シルエットは次の方向とする。

- 足なし
- 手は原則なし
- 丸〜やや横長
- 地面に接している
- 顔は単純
- 体はゼリー・スライム的
- 大きな外付け装飾は避ける

属性差は外付けパーツだけに頼らず、色、透明感、内部模様、ハイライト、泡、火花、渦、小石、軽いエラ・ヒレ・ツノ・触角などで表現する。「地＝岩だらけ」「風＝大きな羽」のように属性ごとに完全な別モンスターにはしない。

## 3. 表情パーツ

仕様書の「3D 共通ボディ＋画像パーツ」方針に合わせ、目・口・眉などを別 PNG にして組み合わせる。初期実装では種類を増やしすぎない。

```text
eyes/
  normal.png
  happy.png
  angry.png
  tired.png

mouth/
  smile.png
  flat.png
  open.png
  sad.png

eyebrows/
  normal.png
  angry.png
  worried.png

cheek/
  blush.png
  star.png
  heart.png
```

すべて同じ描画範囲・基準座標で作る。AI 生成を使う場合も自由構図ではなく、左目・右目・口の位置を固定したテンプレート上で差分を作る。

## 4. 模様・ほっぺ・見た目カスタム

模様やほっぺは能力と分離し、純粋な見た目カスタムとして扱う。

例：水玉、星、波模様、炎模様、岩模様、ほっぺ赤、ハート、小さな傷、キラキラ、背中のライン。

推奨構造：

```text
Pururin2DLayer
├─ base_color
├─ body_marking
├─ cheek
├─ eyes
├─ eyebrows
├─ mouth
└─ effect
```

これらは透明 PNG として重ねる。

## 5. UI アイコン

UI アイコンは AI で一個ずつ自由生成せず、先に統一規格を作る。

### アイコン規格案

- 太めの輪郭
- 角丸
- 正面〜斜め前
- 立体感は軽め
- キャンディ・玩具調
- ハイライトあり
- 背景透明
- 1:1
- 小サイズでも判別可能
- 細かい描き込み禁止

対象例：レース開始、育成、ランキング、図鑑、設定、ヘルプ、報酬、スタミナ、心拍、ブースト、属性、脚質、トロフィー、コース。

最終的には、同じシリーズに見えることを優先する。

## 6. ロゴ・タイトル

タイトルロゴは AI 画像生成に完全依存しない。AI は配色、形、レイアウト、モチーフ、雰囲気の案出しに使い、「ぷるりんレーサーズ」の正式文字は正確な文字として再構築する。

理由は、日本語の生成文字崩れ防止、将来のサイズ変更、多言語対応、ベクター化、UI 再利用である。

推奨構造：

```text
Logo/
├─ symbol
├─ pururin_text
├─ racers_text
├─ checker_decoration
└─ glow/shadow
```

可能なら SVG または高解像度 PNG で管理する。

## 7. タイトル画面の一枚絵

タイトル画面は画像生成 AI と相性がよい。ただし、人型キャラクター中心ではなく、**プルリンを主役**にする。

主題は「かわいい単純なスライム生物が、本気の高速レースをしている」。競馬寄りの速度感なので、大ジャンプではなく、地面すれすれの高速滑走、後方へ伸びる体、カーブでの傾き、ぷるぷる振動、火花・水滴・砂埃・風の軌跡、集団走行、追い抜き、ゴール前の接戦で表現する。

プルリンのシルエットは単純に保ち、**動き・エフェクト・構図で派手にする**。

## 8. 一枚絵のレイヤー分け

可能ならタイトル絵を一枚の完成 PNG だけにしない。

```text
TitleArt/
├─ background
├─ track
├─ pururin_group
├─ foreground_fx
├─ logo
└─ ui
```

完全分離できなくても、背景、キャラ群、前景エフェクト、ロゴ程度に分けると Godot 側で軽いパララックス演出を付けられる。

## 9. レース中 2D エフェクト

レース中の 2D エフェクトは属性と速度感を補助する。常時派手に出さず、速度・ブースト・接触時に強くする。

| 属性 | 表現例 |
|---|---|
| 水 | 小さな水滴、泡、尾を引く透明な水流 |
| 火 | 小さな火花、短い炎、赤橙の残光 |
| 地 | 小石、砂埃、地面接触時の粒 |
| 風 | 薄い流線、小さな葉、渦 |

## 10. ブースト表現

通常走行では大きく変形させない。ブースト時のみ、体が後方へ伸びる、顔が真剣になる、残像、属性別エフェクト、発光、UI 演出を強く出す。ブーストは重要な戦術要素なので、視覚的に明確な状態変化を付ける。

## 11. 2D 看板・文字素材

GOAL、START、CHECK POINT 等は、3D 化するものと 2D で済ませるものを分ける。2D で作る場合も同じアート規格を使う。

- ぷっくり
- 太い文字
- 角丸
- 白フチ
- 色数少なめ
- 遠距離視認性優先

文字は AI 生成結果をそのまま使わず、最終的に正確なテキストとして再構築する。

## 12. AI 画像生成の使い方

AI 画像生成は、**完成素材製造機ではなく、デザイン案＋下地生成ツール**として使う。

向いているもの：キービジュアル、タイトル背景、宣伝イラスト、コンセプトアート、UI 案、ロゴ案、キャラクター設定画、装飾パーツ案。

そのまま使う場合は、背景透明、正面、余白あり、同じ比率、同じ光源、同じ輪郭、同じ質感を厳密に固定する。

## 13. 生成 AI 用の共通プロンプト規格

Puru Codex 側で素材生成プロンプトを作る場合、毎回次の共通指定を含める。

```text
Pururin Racers art style:
cute slime creature,
simple rounded silhouette,
soft jelly-like body,
minimal anatomy,
bright cheerful colors,
clean readable design,
slightly glossy,
toy-like but not plastic-heavy,
thick soft outline when 2D,
no realistic animal anatomy,
no overly detailed fantasy armor,
no complex limbs,
high readability at small size,
friendly racing-game aesthetic.
```

日本語版：

```text
プルリンレーサーズ共通アート規格。
単純なスライム型。
丸く柔らかいシルエット。
ゼリー状の体。
細かい手足は付けない。
明るくポップ。
小サイズでも識別しやすい。
リアルな動物表現は禁止。
複雑な防具・装飾は禁止。
属性差は色、模様、内部表現、小さな装飾で表現。
```

## 14. 最初に作る 2D 素材

優先順位は次の通り。

1. プルリン素体デザインシート
2. 表情テンプレート
3. 属性別の軽い差分
4. UI アイコン基準セット
5. 正式ロゴ
6. タイトル用キービジュアル
7. レース中エフェクト
8. 模様・ほっぺ
9. 宣伝素材

いきなりタイトル絵を完成させるより、先に基本プルリンの見た目を確定する。

## 15. 3D との共通化

2D と 3D で別世界にならないようにする。

共通ルールは、丸い、柔らかい、単純、高視認性、属性は小さな差分、装飾を盛りすぎない、ぷるぷる感、高速時は流線型に少し変形、とする。

2D 設定画は、そのまま Blender MCP で 3D 化する際のリファレンスに使う。

## 16. Puru Codex 側の次タスク候補

最初に **「プルリン素体デザイン仕様 v0.1」**を作る。

```text
正面
斜め前
横
後ろ
高速走行時
カーブ時
ブースト時
表情数種
```

その後、**「装飾パーツ設計」**として、エラ、 小ヒレ、触角、ツノ、小尻尾、背中装飾を別シート化する。これらを確定後、2D UI 素材制作と 3D Blender 制作の両方へ展開する。

## 17. 検討結果と推奨順序

この案は、既存設計の「3D 共通ボディ＋画像パーツ」「模様は能力非影響」「プルリンをレースの視覚的主役にする」という方針と整合している。特に、単純なシルエットを先に固定し、属性差や派手さを色・模様・演出で足す考え方は、視認性と 3D 化の両方に有利である。

一方、次の点は制作時に固定する必要がある。

- 素体画像の基準キャンバス、原点、顔パーツの座標
- 2D と 3D で共有する色・輪郭・光源の基準
- ランタイム素材（小容量・レイヤー分割）と宣伝素材（高解像度・一枚絵）の区別
- AI 生成物をそのまま正式ロゴや正確なゲーム内文字に使わないこと
- 属性差分を増やしすぎず、遠距離での判別を優先すること

### 推奨する制作ゲート

1. 素体デザインシートを確定
2. 表情テンプレートを 4〜6 種程度で試す
3. 主要 UI アイコンを同じ規格で数個作る
4. 2D 看板とレース中エフェクトを追加
5. 正式ロゴとタイトル絵を制作
6. 2D 設定を Blender／Godot の 3D アセットへ展開

**結論:** この方針は採用候補として妥当。ただし、今すぐ全素材を作り始めるのではなく、「素体＋表情＋小規模アイコン」を先に基準化するのがよい。
