**状態:** 制作基準のたたき台（2026/09/14 v0.2〜v0.7フィードバック反映）
**作成日:** 2026/09/14
**対応デザインシート:** [`ぷるりん素体デザインシート_v0.7.png`](reference/ぷるりん素体デザインシート_v0.7.png)
**関連部品設計シート:** [`ぷるりん部品設計シート_v0.1.png`](reference/ぷるりん部品設計シート_v0.1.png)

この文書は、ぷるりんレーサーズの2D素材・3D素材・Godot内の見た目を同じ方向へ揃えるための基準である。数値は初期値であり、実機表示とゲームプレイ確認を通して更新する。

## 1. 基本コンセプト

- 主役は、足や明確な腕を持たない単純なスライム型生物「ぷるりん」
- 丸く、柔らかく、ぷるぷるしていて、地面に接している
- 小さい表示でも顔と属性が読み取れることを優先する
- リアルな動物・人型キャラクター・複雑な防具は基本的に使わない
- 派手さは本体の複雑化ではなく、色・ハイライト・動き・エフェクトで出す
- 生成画像はデザインリファレンスとして使い、正式なロゴ・ゲーム内文字・ランタイム素材は正確に再構築する

## 2. 共通シルエット

### 2.1 必須要件

- 足なし
- 手・前足として見える形は付けない
- 尻尾や後方へ伸びる長い付属物は付けない
- 丸〜やや横長の一体型ボディ
- 底面は地面に接する、またはわずかに潰れる
- 頭と胴体を分けない
- 顔は正面寄りに配置し、目と口だけでも表情が成立する
- 頭頂部や体側に小さな属性アクセントを追加できる

### 2.3 属性別の体側・頭部装飾

- 地属性は体側ヒレを付けず、岩の表現だけを本体の近くに置く
- 水属性はv0.2の小さな半透明の体側ヒレを維持する
- 火属性は現在の水系ヒレではなく、小さな火／悪魔モチーフの体側ヒレを付ける
- 火属性のヒレは尖った炎または小さな悪魔の翼を連想させるが、本体幅から大きくはみ出さない
- 風属性は体側ヒレを付けず、頭頂部に小さな羽毛状の飾りを置く
- 風属性の羽飾りは頭部に密着させ、大きな翼や尾に見えないようにする
- いずれも手、足、ひづめ、腕、尾には見えないようにする

### 2.2 避ける表現

- 大きな翼、長い角、尻尾、重い甲冑などによる別生物化
- 複雑な手足や指
- 過剰なトゲ、細かすぎる模様
- 正面と側面で大きく別の体型になるデザイン
- 本体から大きく突き出す付属物
- 遠距離で本体色と背景が同化する配色

## 3. 属性差分

属性は能力値そのものではなく、視認性と個性を補助する見た目として扱う。共通ボディを残し、色・内部表現・小規模な装飾で差を出す。

| 属性 | 主色 | 補助色 | 表現 | 避けること |
|---|---|---|---|---|
| 地 | `#765638` | `#C89A62` | ヒレなし。大きめの岩・角張った突起、小石、重い接地感、白目がちな目 | 全身を岩の鎧にする |
| 水 | `#2C9FE8` | `#A9E8FF` | 水滴、泡、小さな体側ヒレ、丸く優しい目 | 魚の体型や尾びれにする |
| 火 | `#F0522D` | `#FFB33E` | 火／悪魔を思わせる小さな尖りヒレ、赤橙の残光、少し鋭い目 | 大きな翼、尾、過度に恐い顔にする |
| 風 | `#8AD9CF` | `#E1F7E7` | ヒレなし。頭の小さな羽毛飾り、流線、葉 | 大きな翼や長いリボンを身体に付ける |

共通の輪郭色は `#21435A` を基本とし、地属性のみ暗い茶色を許容する。白いハイライトは左上から入り、透明感のある素材では不透明度を下げた反射を追加する。

## 4. 表情パーツ

表情は本体から分離した透明画像レイヤーとして管理する。すべて同一キャンバス、同一基準座標、同一向きで作る。

目パーツは付け替え前提とし、通常・喜び・怒り・疲れなどの表情差分や、属性別の目デザインを同じ基準座標で交換できるようにする。本体画像へ目を焼き込まず、左右の位置・大きさ・基準点を統一する。

最初の部品設計では、顔なしの共通素体と、通常・喜び・集中・疲れの4種類の目を基準にする。右下の合成例のように、素体と目を重ねたときに位置ずれやサイズ差が出ないことを確認してから、正式な透明PNGへ分離する。

```text
Pururin2DLayer
├─ base_color
├─ body_marking
├─ cheek
├─ eyes
├─ eyebrows
├─ mouth
└─ effect
```

初期セットは次の通り。

```text
eyes/      normal, happy, angry, tired
eyebrows/  normal, angry, worried
mouth/     smile, flat, open, sad
cheek/     blush, star, heart
```

顔の配置は、正面向きの基準ボディに対して左右の目を同じ高さに置き、口は目の下に十分な余白を残す。斜め向きでは顔全体をボディに追従させ、各パーツを個別に大きくずらさない。

火属性のみ、上まぶたをわずかに下げ、目の内側を少し下向きにする。凶暴さは控えめにし、かわいさと小サイズでの視認性を残す。

地属性は白目の面積を大きくし、細めの茶〜黒色の虹彩と瞳を置く。岩の重さと少し強い意志が伝わる目にするが、恐怖表現には寄せない。水属性は丸く大きく、濃い青の虹彩と柔らかなハイライトを持つ穏やかな目を基本とし、鋭い角度や強い眉を避ける。風属性は白目を作らず、濃い青緑〜ミント系の単色に小さなハイライトを入れた、丸みのある横長グロス目にする。風らしい軽快さはわずかな横幅で出し、尖ったまつ毛・鋭い吊り目・威圧感は避ける。水と風は形・色の両方で見分けられることを優先する。

## 5. 動きの見た目

### 通常走行

- 本体の高さはほぼ維持
- 底面だけ軽く伸び縮みする
- 表情は読みやすく保つ
- エフェクトは小さく、常時画面を埋めない

### カーブ

- 進行方向へ少し傾く
- 外側へ大きく倒しすぎない
- 底面の接地を残し、滑っている印象を優先する
- 水属性の体側ヒレは外へ開きすぎず、薄く寝かせる
- 地属性と風属性には体側ヒレを付けない
- 火属性の体側ヒレは短い炎の突起として、身体の近くに収める

### ブースト

- 本体を進行方向へ伸ばす
- 後方に属性色の残光を出す
- 目や眉を真剣な表情へ切り替える
- 発光とエフェクトを通常時より明確に強める

デザインシートの動き表現は演出の方向を示すものであり、そのままアニメーションフレームとして使用しない。

## 6. 2D素材の制作規格

- ランタイム用レイヤーは透明背景PNGを基本とする
- 画像レイヤーは同じ基準キャンバスと原点を使う
- 小サイズ表示で輪郭・目・口・属性色が判別できることを合格条件とする
- UIアイコンは1:1、太めの輪郭、少ない色数、角丸、背景透明を基本とする
- 正式ロゴやGOALなどの文字は、生成画像の文字をそのまま採用しない
- 宣伝用一枚絵は高解像度で別管理し、ランタイム素材と混在させない

## 7. 3D素材の制作規格

- ぷるりん本体は共通ボディを基本にする
- 形状は単純な曲面と柔らかい輪郭で構成する
- 属性差分はマテリアル、模様、小さな装飾パーツで表現する
- 主要な演出対象は別オブジェクトに分ける
- 原点と基準スケールを統一する
- Collisionやルール判定は見た目アセットに持たせない
- Blenderは形状・マテリアル・パーツ分割、Godotは浮遊・回転・発光・パーティクルを担当する

## 8. 推奨フォルダ構成

ランタイム素材を追加するときは、次の構成を基本とする。

```text
client/assets/
├─ pururin/
│  ├─ base/
│  ├─ expressions/
│  ├─ markings/
│  ├─ effects/
│  └─ models/
├─ ui/
│  ├─ icons/
│  ├─ logo/
│  └─ signs/
├─ environment/
│  ├─ course/
│  └─ props/
└─ audio/
   ├─ se/
   └─ bgm/
```

制作途中の設定画や生成画像は `docs/reference/` に置き、ゲームが直接読む素材と区別する。

## 9. 命名規則

- 英小文字とアンダースコアを基本とする
- 種別・属性・状態の順に並べる
- バージョン更新時は既存ファイルを上書きせず、必要に応じて末尾に版を付ける

例:

```text
pururin_base_front.png
pururin_water_front.png
pururin_eyes_happy.png
pururin_effect_boost_fire.png
sign_goal_v01.glb
ui_icon_race_start.png
```

## 10. 制作ゲート

1. 素体の正面・側面・背面が同じ生物に見える
2. 4属性を小サイズで見分けられる
3. 表情レイヤーを同じ基準座標で重ねられる
4. 通常走行・カーブ・ブーストの差が視覚的に伝わる
5. Godot上で本体・表情・エフェクトを独立して調整できる
6. 3D化したときに、不要な細部や過剰なポリゴンが発生しない
