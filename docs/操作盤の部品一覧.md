# 操作盤（ハート型）の部品一覧

左上の操作盤を、絵の部品で組み立てるための一覧です。**絵は素材の側が描き、こちら（コード）は絵を重ねて並べ、値の分だけ見せ、数字と名前を書きます。**

- 下絵：ChatGPT で作ったハート型の操作盤の絵（1536×1024）。部品は、この下絵と同じ位置に描く。
- 部品の一覧の正本：`client/data/config/heart_hud_parts.json`（読み込み・検査は `client/scripts/config/heart_hud_parts_config.gd`）
- 絵の置き場：`client/assets/ui/heart_hud/`
- 組み立てるコード：`client/scripts/presentation/parts_race_hud.gd`（Godot の TextureProgressBar で、増減する部品を値の割合だけ見せる）
- レースの左上の操作盤は、この部品で組み立てている（2026-10-19から）。今の部品の絵は、下絵を切り抜いて、下絵で光っていない所を、隣の光っている所から写して補ったもの。描き直した絵を同じ名前で置けば、差し替わる。

## 絵の決まり（全部の部品で同じ）

1. **大きさは、どれも 1536×1024 の透明な PNG。** 下絵と同じ大きさ・同じ位置に描く（下絵の上に重ねて描けばよい。位置合わせの数字はいらない）。
2. **1つの部品を、1枚に。** 部品のない所は、完全に透明にする（読み込むときに、透明な所を切り落とす）。
3. **数字・名前・単位は描かない。** こちらのコードで書く（下の「文字」）。「Speed」などの決まった言葉も、今はコードで書く。言葉を絵に入れたいときは、`heart_hud_parts.json` の `texts` から、その行を消す。
4. **増減する部品は、「いっぱいのときの絵」を描く。** 空のときの絵（地）は、別の1枚。コードが、いっぱいの絵を、値の割合だけ見せる。
5. 重なる順は、下の表の上から下（あとの絵が手前）。

## 部品の表

「見せ方」の意味：
- **固定**：いつも全部見せる。
- **弧（時計まわり／反時計まわり）**：弧のまん中から見て、決まった角度から、値の割合だけ見せる。角度は、12時を0として時計まわりの度。
- **下から上**：絵の、いちばん下からいちばん上までのうち、値の割合だけ下から見せる。
- **1本ずつ**：ノッチ・ブーストの棒を1本1枚で描く。今の数まで見せる。

## 文字（コードで書く）

`heart_hud_parts.json` の `texts` に、場所（下の線の左はし。`align: center` ならまん中）・大きさ・色を書く。座標は下絵と同じ。

| 文字 | 場所 |
|---|---|
| 名前（トレーナー名） | (400, 142)。幅 440 に収まらない長い名前は、小さく・細くして収める |
| aero の「aero」と値「68 %」 | (115, 270) と (95, 365) |
| 「Speed」と値「63 km/h」 | (540, 225) と (690, 262) |
| 「Notch」と値 | (1065, 255) |
| 「Stamina」と値「69 %」 | (475, 795) と (500, 890) |
| 体力の「0」 | (828, 785) |
| 心拍数「143 bpm」 | まん中 (655, 552) |
| 「Boost」と「( 3 )」 | (1062, 842) と (1050, 905) |
| 「Dash」と「(∞)」 | (1305, 800) と (1300, 858) |
| 属性の印 | まん中 (965, 110) |
| 脚質の印 | 左はし (1060, 110) |

## 描いた絵を確かめる

`client` で次を実行すると、見本の値（下絵と同じ値）で組み立てた操作盤を PNG に保存する。まだ無い絵は、名前を表示する。

```bash
../tools/godot/Godot_v4.7-stable_linux.x86_64 --path . -s res://scripts/debug/parts_hud_preview.gd -- 保存先.png
```

絵を別の場所に置いて試すときは、最後に、その場所を足す（`-- 保存先.png 絵の置き場`）。
