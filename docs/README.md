- [設定管理](設定管理.md)：設定ファイル・画面・操作の対応。
- [レース操作マニュアル](レース操作マニュアル.md)：遊ぶ人向けの、レース中の操作の説明。
- [ローカルレース計算リファレンス](現行ローカルレース計算リファレンス.md)：実装の数式と内部処理。
- [検討事項](検討事項.md)：未決事項と過去の決定履歴。過去ログは現在の仕様とは限らない。
- [Godot撮影資料](reference/key_visuals/game_look_v01/README.md)：現在の画面背景の元画像を含む。撮影用コースと実走コースの差に注意。
