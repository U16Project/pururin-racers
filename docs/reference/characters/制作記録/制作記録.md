# CPUトレーナー画像 v02 制作記録

## 採用方針

ユーザーが確認したレンのサンプルを基準に、15人をシンプルで可愛い人物アイコンに揃える。大きな丸い顔・短い頭身・少数の色・読みやすい輪郭とし、写実的な質感や装飾過多を避ける。男女の騎士、町の職業、年齢が見分けられる服や髪を使う。王冠でオルドの正体を示さない。

当初の手続描画サンプルとは異なり、**v02はユーザーが確認した画像生成サンプルの絵柄を採用した画像**。非AIの旧v01と混同しない。

以下は制作指示・選定の**要約**であり、生成ツールへ投入したプロンプト原文や完全な再現ログではない。CPUの操作方針を画像から新しく決めたものでもない。

## 素材の管理

- 元画像の生成先：`/home/u16/.codex/generated_images/01a09136-a9ca-7371-8ea5-a3f2ad18ca41/`
- ゲームが読む画像：ハヤテ・イブキ・ツバキ・ヒナタ・ダイチ・ミナトは `client/assets/ui/cpu_trainers/{id}_v03.png`、他9人はv02。
- 元画像は保持。ゲーム用はユーザー指定の1024×1024 RGBへ、PillowのLANCZOSで寸法だけ変換する。描き足し・色変更・切り抜きはしない。
- 旧v01は消さず比較用に残す。非採用試行も自動削除しない。
- 人物・紹介・得意脚質は[人物設定一覧](../../../CPUトレーナー人物設定.md)、実行時の対応は `client/data/config/cpu_trainers.json`。

## 髪型の区別によるv03差し替え

ユーザーから、若い男性の髪型が似すぎているとの指摘を受け、ハヤテとイブキだけ髪型を変えた。旧v02・生成原本を残し、JSONのこの2人の画像パスだけをv03へ変更。紹介文・脚質・CPU判断設定・他13人の画像は変更しない。以下は指示の要約であり、プロンプト原文ではない。

- ハヤテ：額が見える非常に短い刈り上げ。元画像 `exec-e3692b55-c4fa-4029-8a63-3fe96041f37b.png`（1254×1254）。ゲーム用1024×1024 RGB、SHA-256 `fa2417f220a44862ddb5de2124c42a3572af1aa59560cbc1638a750b53b50301`。
- イブキ：額が見える丸い巻き毛。元画像 `exec-00f3cc38-e4c1-44d9-98d3-6420015153e7.png`（1254×1254）。ゲーム用1024×1024 RGB、SHA-256 `ab9206ddfc703c87b7a74a38f8299e5c4e2dd2ecefbf5516c539aadfac7b1fa6`。

続いてツバキとヒナタも、髪型の区別を目的にv03へ差し替えた。こちらも旧v02を保持し、画像の参照先だけを変更した。

- ツバキ：額を全て出して後ろで結ぶ髪。元画像 `exec-68e14282-e768-485b-932f-d7e41f849141.png`（1254×1254）。ゲーム用1024×1024 RGB、SHA-256 `9957e8f0e8fdfa1b48cbae0922165e509ef225f4e043fd8eedc6d05090504159`。

その後、ユーザー指定でダイチ・ミナトの外見もv03へ差し替えた。紹介文と農園主・船乗りという設定、得意脚質、CPU判断設定はそのまま。
