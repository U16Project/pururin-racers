## 共通の描き方

- 1人で立つ。頭から膝の少し下まで。手と立ち方が見えるようにする。
- 背景は、その人のいる場所をうすく描いた景色で、画面全体に広げる。人物は無地の背景で描き、切り抜いて背景に重ねる。
- そろえるのは描き方だけ。線に太い所と細い所。影は1段。色は一人3色まで。頭の大きさや胴の太さは、年齢と体格でちがってよい。
- 見分けの決め手は顔（輪郭・目・鼻・口の並び）と立ち方（重心）。小物は一人一組まで（帳面と鉛筆で一組）。
- 髪は、頭の外側の形・前髪・耳・襟足まで、人ごとに違う形にする。
- 体の比率は年齢どおり。表情は明るく、眉はまっすぐか、ゆるい弧。
