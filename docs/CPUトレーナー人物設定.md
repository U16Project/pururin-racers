# CPUトレーナー人物設定

2026/10/11採用。[基本世界観](世界観設定.md)に合わせた15人の人物・紹介文。

走るのはぷるりんで、トレーナーは指示を送る。紹介文の「得意な脚質」は人物設定・画面表示であり、その戦術がCPUに実装済みという意味ではない。（2026-10-25に、判断設定 `profile_id` と前のCPU判断処理は消した。CPUの席は育てたCPUが走らせ、性格は `cpu_trainers.json` の `frame` で伝える。）職業や正体による能力補正はない。

実行時の紹介文・画像パス・得意脚質は `client/data/config/cpu_trainers.json` が管理する。画像は全員1024×1024。ハヤテ・イブキ・ツバキ・ヒナタ・ダイチ・ミナトは外見を区別した `client/assets/ui/cpu_trainers/{id}_v03.png`、他9人はv02を使う。旧v01と、差し替え前のv02は比較用として保持する。

## ユウ（yuu）

- 人物：男性・レース場の見習い
- 得意な脚質：先行

レース場で働きながら、トレーナーの腕を磨く青年。集団の中で温存して、最後の直線で一気に抜け出す。

## ホムラ（homura）

- 人物：男性・市場の配達人
- 得意な脚質：逃げ

市場と町の店を行き来する、元気な配達人。とにかくスタートダッシュで、ほかのプルを置き去りにして、ぶっちぎりでゴールを目指す。

## シズク（shizuku）

- 人物：女性・農園の水路番
- 得意な脚質：先行

農園の水路を手入れする女性。中盤は全体のペースに合わせて柔軟に走りを変え、終盤は早めに良い位置をキープし仕掛ける。

## ダイチ（daichi）

- 人物：男性・農園主
- 外見：少年風の丸顔と細い肩。外見指定によって農園主という人物設定は変更しない。
- 得意な脚質：差し

城下町へ野菜を届ける農園主。序盤は集団の中で力をため、前が疲れたころから、じわじわと長く追い上げる。

山を越える旅人を案内する青年。後ろでじっと待ち、仕掛けると決めたら、外から一気に抜き去る。

## アカリ（akari）

市場でパン屋を営む、気さくな女性。集団を引き連れ、トップを追い、直線で押しのけ、一気にゴールを目指す。

港で荷船に乗る船乗り。集団の後ろで力を残し、前が開いたら、すぐ隙間を抜けて追い上げる。
