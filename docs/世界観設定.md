# ぷるりんレーサーズ — 世界観設定

2026/10/11採用。細かなストーリーとは切り離し、現在の基本世界観を保存する。

## 基本設定

- ミオが、夢の中でぷるりんたちのいる世界に迷い込む。
- 舞台は中世風の城下町。その中にレース場がある。
- 市場や農園があり、海には港がある。
- 遠くには、高くそびえ立つ山々がある。
- トレーナーたち、王様、后、騎士が暮らしている。

## ミオ

2026/11/10採用。

- 13歳の女の子。現実の世界から、夢の中でこの世界に迷い込む。
- 好奇心が強く、少し負けず嫌い。本が好きで、空想がち。小説を書こうと、いろいろ模索している。
- 見た目：赤みのある深い栗色の、あご下までのボブ。左の毛先が大きく外にはねる。前髪は右へ斜めに流す。細い茶色の丸いメガネ。
- 服：制服（白い丸襟シャツ、紺のベスト、えんじ色のリボン、紺のスカート）。胸ポケットに角の折れたノート。
- 絵の姿：文庫本を胸の前で片手で抱え、少し上の遠くを見て、物語を思い浮かべるようにほほえむ。背景は、朝の城下町の開けた広場。

## 場所

2026/11/15採用。トレーナーの背景の絵に描いた場所を、1つの町にまとめたもの。

| 場所 | ひとこと | いる人 |
|---|---|---|
| 王城 | 町でいちばん高い丘の上。町のどこからでも見える | レン、オルド、王様・后 |
| 城の庭 | 城の中の、生け垣とバラと噴水の庭 | オルド |
| 城門 | 城下町から城へ上る坂の上にある大きな門 | レン |
| 中央広場 | 町のまん中。噴水があり、ミオが最初に来た場所 | ミオ |
| 市場通り | 広場から港へ下る、にぎやかな通り | ホムラ、アカリ |
| 宿屋通り | 広場の横の、石だたみの細い通り | ヒナタ |
| レース場 | 町のはずれの、いちばん広い平らな所 | ユウ、カエデ |
| 港 | 町の南、海に面した船着き場と魚市場。灯台が見える | ミナト、ロッタ |
| 農園 | 町の東に広がる畑と水路 | ダイチ、シズク |
| 見張りの道 | 町を囲む低い石垣にそった道 | ツバキ |
| 石切り場 | 町の西、山に入る手前の岩場 | ガンテツ |
| 山麓の牧場 | 北の山のふもとの草地 | イブキ |
| 山道 | 牧場から高い山々へ続く道 | ハヤテ |

町の並び：北に高い山々（ふもとに牧場、その先に山道）。西に石切り場。真ん中の丘に王城、その下に中央広場・宿屋通り・レース場。東に農園。南へ市場通りが下り、港と海に出る。町のまわりを見張りの道が囲む。

## 今は決めないこと

細かなストーリー、ミオの家族や現実での暮らし、夢の仕組みや現実世界との往来、時間の進み方、記憶に関する仕組み、人物同士の関係や具体的な事件は未決とする。

旧資料の小説執筆などの設定は、今回の基本設定から自動的に引き継がない。また、採用した世界観の保存は、各場所・人物・導入シーンがゲーム内に実装済みであることを意味しない。
