# Blender MCP：Nene制作手順書（トポロジー優先）

この文書は、Blender Agent Bridge／Blender MCPを使って、Nene（猫目ネネ）のゲーム用アニメ調キャラクターを制作するエージェントの参照手順である。

## 用語の修正：単に「連続」と書かない

「連続メッシュ」「連続トポロジー」という表現だけでは条件不足である。球体・円柱をつないだロボットでも、メッシュがつながっていれば「連続」を満たしてしまう。

この手順書で求めるのは、次の4条件を同時に満たす**女性キャラクター用の人体ベースメッシュ構造**である。

- 胸郭、ウエスト、骨盤の幅と厚みが明確に変化し、寸胴になっていない
- 胸、臀部、大腿、ふくらはぎに、円柱ではない曲面ボリュームがある
- 肩、脇、股関節、膝が、人体の分岐と曲げを考えた面の流れになっている
- 目、鼻、口、顎、耳が、顔の変形を考えたループでつながっている

以後、「連続」とだけ書かず、必ず「女性ベースメッシュの形状・分岐・変形ループ」と具体的に記述する。

## 0. この手順書の結論

本番メッシュを、AIに一括生成させて後から検査する方法は採用しない。

Blender公式マニュアルでは、自動リメッシュは変形用キャラクターの最終トポロジー作成には適さず、変形部位に沿ったトポロジーは手動で作る必要があると説明されている。したがって、MCPは「調査・参照配置・段階的な編集補助・検査・証拠取得」に使い、顔と関節の本番トポロジーは、既存の実績あるベースメッシュの利用または手動リトポロジーを中心に進める。

参照：<https://docs.blender.org/manual/en/dev/modeling/meshes/retopology.html>

## 1. 採用する制作方式

### 第一選択：実績のあるベースメッシュを変形する

ライセンスが確認でき、ワイヤーフレームを確認できるゲーム用・アニメ用女性ベースメッシュがプロジェクト内にある場合は、それを複製してNeneの形状へ調整する。

- AIにゼロから人体トポロジーを計算させない
- 頂点・面の接続構造を維持したまま、形状、比率、シルエットを調整する
- 目、口、肩、脇、股関節などの既存ループを壊さない
- 出典、ライセンス、元ファイル、変更履歴を記録する

### 第二選択：ハイポリ形状から手動リトポロジーする

適切なベースメッシュがない場合は、形状確認用のブロックアウトまたはスカルプトを別に作り、本番用の低密度メッシュを別オブジェクトとして手動で張る。

- 形状用メッシュと本番トポロジーを同じものとして扱わない
- 最初に顔の主要ループを計画する
- Face ProjectまたはShrinkwrapで参照形状へ吸着させる
- 目・口・鼻・顎のループを作ってから周囲を接続する
- 胴体と四肢は、肩・脇・骨盤・股関節の分岐を考慮して接続する

Blender Studioの教材でも、顔のedge flow、表情変形、ポール、パッチを分けて扱い、頭部と身体を段階的にリトポロジーしている。

参照：<https://studio.blender.org/training/stylized-character-workflow/chapter/5d384edea5b8f5c2c32c8507/>

## 2. 参考資料の扱い

参考資料は、次の3種類に分ける。

### A. Neneの形状資料

顔立ち、髪型、体型、配色、シルエットの基準にする。

- 正面、45度、側面、背面を分けて管理する
- 不足している角度は勝手に確定しない
- 不足角度を補う場合は、仮設計として明示し、制作前に承認を得る

### B. トポロジー資料

目・鼻・口・顎・首・肩・脇・骨盤・関節のループ構造を確認するために使う。

- 見た目のデザイン資料と混同しない
- ワイヤーフレームが見えない画像は、トポロジーの根拠にしない
- 四角面の数だけで良し悪しを判断しない
- 変形部位の流れ、ループの連続性、ポールの位置を見る

### C. 実メッシュ資料

利用条件が明確な無料ベースメッシュを優先する。

- 購入やダウンロードは事前承認が必要
- ライセンス不明のモデルは制作へ流用しない
- 実メッシュは、まず表示のみでワイヤーフレームを確認する
- そのままNeneへ改変する前に、トポロジーの採用理由を報告する

実制作資料でも、公式または利用許諾されたゲームモデルをワイヤーフレーム表示で研究する方法が紹介されている。

参照：<https://www.therookies.co/blog/breakdowns/production-ready-character-head-pipeline-anime-to-photoreal>

### 今回追加した参考画像

これらは完成モデルの流用元ではなく、Neneの本番メッシュを設計するためのトポロジー参考資料である。画像の作者・掲載元・利用条件が確認できないものは、参考表示と構造研究だけに使用し、制作物へそのまま転載・同梱しない。

- [女性ベース素体・正面](reference/topology/female_base_front.jpg)：胸郭、ウエスト、骨盤の幅変化、胸・臀部・大腿の曲面ボリューム、肩・脇・股関節・膝の面の流れを確認する。
- [女性ベース素体・背面](reference/topology/female_base_back.jpg)：背中、腰、臀部、骨盤、脚裏側の形状と面の流れを確認する。正面だけで体型とトポロジーを決めないために使用する。
- [アニメ顔トポロジー](reference/topology/anime_face_topology.jpg)：目の周囲、鼻、頬、口、顎、耳、首へ流れる比較的単純な顔ループの参考。
- [アニメ頭部トポロジー](reference/topology/anime_head_topology.jpg)：3Dの頭部で、眼窩・鼻・口・顎・耳の面の流れと立体的な接続を確認する。

今回の意図は、単に女性らしい輪郭を生成することでも、メッシュをつなげることでもない。上記のような「胸郭・ウエスト・骨盤の幅変化、人体の分岐、顔と関節の変形ループを備えた女性ベース素体」を先に用意し、その上へNeneの顔立ち・髪型・体型を調整することである。

参考画像から採用するのは、次の構造原則である。

- 目と口を囲む閉じたループ
- 鼻、頬、口、顎へつながる面の流れ
- 頭部から首、胸郭、腰、骨盤へ続く断面の変化
- 肩、脇、股関節、膝に合わせた変形用ループ
- 正面と背面で破綻しない、胸郭・ウエスト・骨盤の幅変化を持つ胴体と四肢

画像の見た目や作者固有のモデルをそのまま再現することは目的にしない。Neneの設定画に合わせて形状を変えるが、変形に必要な構造原則は維持する。

## 3. 編集前の停止条件

最初は読み取り専用で、以下だけを行う。

1. プロジェクトのドキュメント、既存Neneファイル、参考画像を読む。
2. Blenderシーン、オブジェクト、コレクション、モディファイア、保存状態を確認する。
3. 候補ベースメッシュの出典とライセンスを確認する。
4. 顔と身体のワイヤーフレーム参考を提示する。
5. 採用方式、作業段階、想定面密度、検証方法を提示する。

この段階では、メッシュ生成、既存ファイルの削除、保存、書き出し、ダウンロードを行わない。ユーザーが明示的に「OK」と言うまで停止する。

## 4. 本番トポロジーの構築順

### Phase 1：基準と保全

- 既存ファイルを新しいバージョン名で複製する
- v01の球頭、円筒肢、浮いた顔リング構成を本番メッシュとして流用しない
- 元ファイルと作業ファイルを分ける
- `SOURCE_REFERENCE`、`SHAPE_BLOCKOUT`、`RETOPO_BASE`相当の役割をコレクションで分離する
- Mirrorを使う場合は、中心線、原点、クリッピング状態を確認する

### Phase 2：顔の主要ループ

頭部全体を一括生成せず、次の順で作る。

1. 目の周囲に閉じたまぶたループを作る
2. 口の周囲に上下唇と口角を制御できるループを作る
3. 鼻翼・鼻下・頬を目と口の流れへ接続する
4. 顎から頬、口角、耳、額へ外周の流れを作る
5. 残りの頭蓋と後頭部へ面を広げる
6. 首へ連続させる

顔の変形部位には十分な密度を置く。口のループを口角で突然止めず、変形の少ない場所へ流して終わらせる。三角形やポールは存在だけで失格にせず、陰影と変形への影響で判断する。

参照：<https://wiki.frozenbyte.com/index.php/3D_Asset_Workflow:_Retopology>

### Phase 3：首・胴体・骨盤

- 首は棒を頭部へ接続するのではなく、頭部、首、肩、胸郭への流れを作る
- 胸郭から腰、骨盤へ、断面の変化が滑らかに続くようにする
- 胸部、腰、骨盤の幅は、数値だけで決定せず、Neneの正面・45度・側面資料と照合する
- 腰を細くする場合も、別円柱を置かず、本体メッシュの面を変形する
- 肩と脇は腕の付け根へ分岐する構造を作る
- 骨盤と股関節は大腿部へ分岐する構造を作る

「首から股関節までを一本の円環押し出しだけで作る」方法は、肩・脇・腕、骨盤・股関節・脚の分岐を表現できないため、本番の人体トポロジーの規則にはしない。

### Phase 4：四肢と関節

- 肩、肘、手首、股関節、膝、足首に曲げ用のループを置く
- 腕と脚を単純な円柱のまま接続しない
- 肩と股関節は胴体から自然に分岐させる
- 末端部はゲーム上の必要密度に合わせて簡略化する
- シルエットへ影響する部位は、カメラ距離を基準に密度を決める

ゲーム用制作資料でも、変形する脇・膝・口角などは、静的な部分よりも変形時の見え方を優先し、きれいなedge flowがリギングとウェイト作業を容易にすると説明されている。

参照：<https://wiki.frozenbyte.com/index.php/3D_Asset_Workflow:_Retopology>

### Phase 5：髪と別パーツ

本体トポロジーの承認後に追加する。

- 髪は頭部に密着する頭皮キャップ、前髪、側面、後ろ髪に分ける
- 髪の根元と流れを正面・45度・側面で確認する
- 顔に浮いたリングや板を貼り付けない
- 目玉、まつ毛、口内、衣装は別オブジェクトでもよいが、顔の変形ループを代替しない
- 髪や衣装で隠れるからという理由で、本体の不良トポロジーを許容しない

## 5. MCPでの実行単位

MCPエージェントには、各Phaseを別タスクとして実行させる。

### 調査タスク

シーン、ファイル、参考資料、候補ベースメッシュを読み取り、編集せずに報告する。

### 顔トポロジータスク

顔の主要ループだけを作成またはリトポロジーし、ワイヤーフレームを提示して停止する。

### 身体トポロジータスク

顔の承認後に、首、胸郭、腰、骨盤、肩、脇、股関節だけを追加し、ワイヤーフレームを提示して停止する。

### 四肢タスク

身体の承認後に四肢と関節を追加し、変形テスト用の簡易ポーズを提示して停止する。

### 髪・マテリアル・カメラタスク

本体と変形の承認後に、髪、顔の別パーツ、マテリアル、固定カメラを追加する。

1回の指示で全身、髪、顔パーツ、マテリアル、カメラ、書き出しを作らない。

## 6. 検証方法

### トポロジー表示

各Phaseで必ず以下を提示する。

- 正面ワイヤーフレーム
- 45度ワイヤーフレーム
- 側面ワイヤーフレーム
- Subdivision前後の比較
- 顔または関節の拡大表示

### 構造検査

- Mirrorの中心線と重複頂点
- ルーズジオメトリ
- 意図しない境界辺
- 非多様体
- 重複面・内部面
- Ngonの場所と理由
- 法線方向
- 面密度の急変

### 変形検査

顔：

- まばたき
- 口角を上げた笑顔
- 口開閉
- 顎の開閉

身体：

- 腕を45度・90度上げる
- 肘を曲げる
- 股関節を前後に曲げる
- 膝を曲げる
- 首を左右に傾ける

数値検査が通っても、ワイヤーフレームまたは変形表示が不自然なら不合格とする。

## 7. 合格条件

以下をすべて満たすまで次のPhaseへ進まない。

- Neneの形状資料と正面・45度・側面で大きく矛盾しない
- 顔に目・鼻・口・顎へつながる意味のあるedge flowがある
- 肩、脇、骨盤、股関節に変形用の流れがある
- 本体が球体・円柱・浮遊パーツの積み木に見えない
- Subdivision後の陰影と輪郭が成立する
- 基本ポーズで破綻や大きな潰れがない
- ワイヤーフレームと変形テストを提示済みである
- ライセンスと作業ファイルの出典が記録されている

## 8. 即時停止条件

依頼文やエージェントの計画に、次の表現があれば実行を止める。

- 「一括で作成する」
- 「まず形を作り、edge flowは後で検査する」
- 「球体・円柱を組み合わせて本体を作る」
- 「面数を増やせばトポロジーが改善する」
- 「非多様体0なので完成」
- 「ワイヤーフレームは不要」

停止後は、変更済みオブジェクト、保存状態、未検証箇所、修正版の段階計画だけを報告する。勝手に削除、Revert、上書き、追加生成を行わない。

## 9. 資料から採用しない内容

以下は参考会話に含まれていたが、本番手順には採用しない。

- ウエストを一律0.6倍にすれば女性らしくなるという固定値
- 胴体を別々の球体・円柱モジュールで組み立てる方法
- 一本の円環を首から股関節まで押し出せば人体トポロジーになるという説明
- ベベルを適用すれば人体のedge flowが成立するという説明
- バウンディングボックスやレンダーの自己評価だけでトポロジー合格とする方法

これらはシルエット検討用の補助案にはなり得るが、顔・関節・変形用の本番トポロジーを保証しない。

## 10. 最初にエージェントへ渡す短縮指示

```text
この手順書を最初に読み、内容を制作規則として適用してください。

最初は読み取り専用で、プロジェクト資料、既存Neneファイル、参考画像、候補ベースメッシュ、ライセンス、現在のBlenderシーンを調査してください。

頭・体・髪・顔パーツ・マテリアル・カメラを一括生成してはいけません。edge flowを後で検査することも禁止します。

自動リメッシュやプリミティブの積み木を本番トポロジーに使わず、実績のあるベースメッシュの変形、または形状メッシュからの手動リトポロジーを提案してください。

調査結果、参照ワイヤーフレーム、採用候補、ライセンス、段階計画、各段階の検証方法だけを提示し、私が「OK」と言うまで編集・保存・削除・ダウンロードを行わないでください。
```
