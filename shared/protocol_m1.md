# M1 通信契約（WebSocket + JSON）

クライアントとサーバーが同じ意味で使う **M1 用** の最小契約。  
輸送: WebSocket（テキストフレーム）+ JSON。UDP は使わない。

## 接続

| 項目 | 値 |
|------|-----|
| 待ち受け | `127.0.0.1:18765` |
| URL（クライアント） | `ws://127.0.0.1:18765` |

※ ポート **8765 は使わない**（18765 固定）。

## 共通フィールド

| キー | 型 | 説明 |
|------|-----|------|
| `v` | number | 契約バージョン。M1 は **1** |
| `t` | string | メッセージ種別（wire 上の type） |

## Client → Server: `ping`

```json
{"v": 1, "t": "ping"}
```

- 接続後、クライアントが送る疎通確認。
- 追加フィールドは M1 では送らない（無視してよい）。

## Server → Client: `pong`

```json
{"v": 1, "t": "pong", "server_time": 1710000000.123}
```

| キー | 型 | 説明 |
|------|-----|------|
| `server_time` | number | サーバーが応答した時刻（UNIX 秒、小数可） |

- `t` が `"ping"` かつ `v` が `1` のときだけ `pong` を返す。
- それ以外の JSON / 不正なメッセージは無視してよい（接続は維持）。

## 体験の完了条件（M1）

- クライアント: Path 上で 1 体が走る
- クライアント: `pong` を受け取り、画面またはログで分かる
