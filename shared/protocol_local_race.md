# ローカル簡易レース（画面ライフサイクル）

新しい wire message はない。サーバーには接続しない（検討事項 #23）。
速度単位は検討事項 #24（km/h）。
周回形状は [`course_layout_m5.json`](course_layout_m5.json)（設計案の標準コース）。

## 画面

1. `res://scenes/m3_intro.tscn` を起動する。
2. **レース開始** で `res://scenes/local_race.tscn` へ進む（オフライン）。
3. **集団プロトタイプを試す（M4）** と **オンラインレースを試す（M5）** は別シーン。
4. **控室へ進む** は従来どおり `res://scenes/m2_run.tscn`（M1/M2 契約）。

## 仮レースルール（要約）

| 項目 | 内容 |
|------|------|
| コース | 標準オーバル。周長 2083.1 m、直線 680 m、半径 115.085 m、幅 15 m、1:1。2000 m の route は `m5_2000` |
| 距離 | 2000 m。スタートは本線 483.1 m（ホーム直線上、最初のコーナーまで約 197 m）。ゴールの意味位置は path 400 m（ゴール後の直線は約 280 m） |
| プル数 | 8。プレイヤー最内枠 |
| 操作 | 左右＝ライン。上下＝出力ノッチ（現行 −3〜+6）。V で目標スピード方式（±1 km/h、下限 48、上限＝自最高速）へ切り替え |
| 最高速 | 各ぷるりんの最高速・加速力の有効値から、自然到達速度と推進補正を導く。プレイヤー上限 75（絶対上限 90）。発進時の最低速度は設定（現行 40） |
| 接触 | `distance` / `offset` の自前判定。候補位置が他走者と重なる場合はその方向へ移動しない。接触後に後方へ位置補正せず、前が塞がれたら接触手前で進行だけを止め、余った出力は空回りする。横の空きができれば前方スロットへの移動を再試行する。ドラフトあり。1.5m以上前方かつ前方・横方向の効果範囲内にいる全走者を直接寄与に使い、横ずれは緩やかな指数減衰を掛ける。効果の載せ方は出力方式と目標スピード方式で異なる。ゴール済みも結果表示まで接触・ドラフトの受給／供給を続ける |
| 状態 | 心拍とスタミナは HUD の仮表示。着順の判定には使わない |
| 出力診断 | 出力走行中は、推進力・転がり抵抗・空気抵抗（二乗）・ドラフト軽減・計算加速度を HUD と Godot ログへ `km/h/s` で表示する。HUD は生のドラフト受取率とは別に、応答曲線後の実効率と速度上限補正も表示する |
| CPU | `local_race.json` の間隔で戦略・ライン追従を選び直す。前方走者を距離・横位置の共通スコアで選び、中央・内側斜め後方・外側斜め後方・必要時の大きな外回りを、混雑・内寄り・追い抜き意図で同じ式により評価する。カーブでは既存のコース幾何による `distance_multiplier`（内側ほど短い）も候補スコアへ反映する。直線では内外差を付けない。外側への追加スタミナ・心拍負荷は加えない。外回りは前方候補が混雑した時に進路を確保する共通則で、特定キャラ・距離区間の特例は置かない。候補がいない場合も、現在ライン・周囲密度・前方の空き・内寄り傾向・ライン変更量を同じ連続スコアで評価し、空いているラインは維持し、混雑時だけ横位置を変える。追従車間では目標速度を少し抑え、遠い時の追走・近すぎる時の減速は同じ車間補正で行う。各 CPU の自然到達速度は自身の最高速・加速力の有効値から導く |
| UI | Esc＝一時停止＋タイトルへ戻る。HUD に経過時間、全員ゴール後2秒で着順とゴールタイム→タイトルへ戻る |

タイム表示は 1 分未満を `58.4`、1 分以上を `1:23.4` の形式にする。M5 の百分の一秒表示とは別。

ゴール時点で着順とゴールタイムを固定する。結果表示までの移動・接触・ドラフトによって、これらの確定値を再計算・変更しない。

M4 は標準コースに載っていない。直線 526 m、半径 164 m、スタート path 609、ゴール path 526 の旧寸法のまま。

ドラフトの受取上限・速度補助上限・前方最小／最大距離・横幅・横ずれ減衰・連鎖減衰は [`m5_draft_rules.json`](m5_draft_rules.json) を正本とする。前方・横方向の効果範囲内にいる全走者を直接寄与に使い、対象数の上限は置かない。現行の横方向範囲は3.0m、横ずれ減衰指数は0.35。ローカル出力方式だけの空気抵抗軽減と応答曲線は `client/data/config/local_race.json` に残す。
