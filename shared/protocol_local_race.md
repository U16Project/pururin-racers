# ローカル簡易レース（画面ライフサイクル）

新しい wire message はない。サーバーには接続しない（検討事項 #23）。

## 画面

1. `res://scenes/m3_intro.tscn` を起動する。
2. **レース開始** で `res://scenes/local_race.tscn` へ進む（オフライン）。
3. **控室へ進む** は従来どおり `res://scenes/m2_run.tscn`（M1/M2 契約）。

## 仮レースルール（要約）

| 項目 | 内容 |
|------|------|
| コース | 東京芝 A 準拠スタジアム近似。周長 2083 m、直線 526 m、半径 164 m、1:1 |
| 距離 | 2000 m。ゴールはホームストレート終端（path 526）。スタートは path 609 |
| 頭数 | 8。プレイヤー最内枠 |
| 操作 | 左右＝ライン、上下＝目標スピード（±1、下限 8、上限＝自最高速） |
| 最高速 | CPU は 14 / 15 / 16、プレイヤーの上限は 25 m/s |
| 接触 | 前方ブロック時は減速し、重なりそうな場合は後ろへ位置補正する。ドラフトなし |
| UI | Esc＝一時停止＋タイトルへ戻る。HUD に経過時間、全員ゴール後2秒で着順とゴールタイム→タイトルへ戻る |

## 既存契約

- 控室接続は [`protocol_m3.md`](protocol_m3.md) / [`protocol_m2.md`](protocol_m2.md) を参照。
- タイム表示は 1 分未満を `58.4`、1 分以上を `1:23.4` の形式にする。
